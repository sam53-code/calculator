# calculator-

A simple calculator built with HTML, CSS, and JavaScript as part of "The Odin Project" (https://www.theodinproject.com/).

Features

- Addition, subtraction, multiplication, and division.
- Single display input.
- Clear button to reset the calculator.
- Interactive buttons for entering numbers and operators.

Built With

- HTML5
- CSS3
- JavaScript

How to Run

1. Clone or download this repository.
2. Open "index.html" in your browser.
3. Use the calculator buttons to perform calculations.

What I Learned

- Working with DOM elements.
- Handling click events.
- Writing and calling functions.
- Managing calculator state using variables.
- Performing arithmetic operations in JavaScript.

Future Improvements

- Add decimal number support.
- Add backspace functionality.
- Support keyboard input.
- Handle invalid operations and repeated calculations.
